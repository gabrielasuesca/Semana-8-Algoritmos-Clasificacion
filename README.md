## Descripción del proyecto

Este proyecto tiene como objetivo comparar cinco algoritmos de
clasificación supervisada utilizando el conjunto de datos
IBM Telco Customer Churn.

El propósito es evaluar el desempeño de los modelos en la
predicción del abandono de clientes de una empresa de
telecomunicaciones.

## Conjunto de datos

**Nombre:** IBM Telco Customer Churn

**Fuente:** IBM

El conjunto contiene información relacionada con los clientes,
los servicios contratados y la facturación.

La variable objetivo es `Churn`, que indica si un cliente
abandonó la empresa.

## Algoritmos implementados

1. Decision Tree
2. Random Forest
3. Support Vector Machine (SVM)
4. K-Nearest Neighbors (K-NN)
5. Naive Bayes

## Metodología

El proyecto comprende las siguientes etapas:

- Exploración de los datos.
- Preparación y transformación de variables.
- División de los datos en entrenamiento y prueba.
- Entrenamiento de los cinco modelos.
- Evaluación y comparación de resultados.
- Interpretación de las métricas y conclusiones.

## Métricas de evaluación

Los modelos se comparan mediante:

- Accuracy
- Precision
- Recall
- F1-score
- Matrices de confusión
